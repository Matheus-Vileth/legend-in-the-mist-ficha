# Guia do jogo (mascote e balão) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um guia com roteiro (sem IA) dentro do site: o mascote Piu com balão de dicas por passo, glossário com busca, termos sublinhados nos textos e interruptor ligado/desligado que lembra a escolha.

**Architecture:** O conteúdo vive em dados (`guide-data.js`); a lógica testável fica em funções puras (`guide.js`: dicas, busca, `linkTerms`, preferências); a interface (`guide-ui.js`) só desenha. O `app.js` monta o interruptor no topo e avisa o guia a cada troca de passo.

**Tech Stack:** JavaScript ES modules, Node 24 (`node --test`), sem dependências novas.

**Spec:** `docs/superpowers/specs/2026-11-21-guia-design.md` (+ `2026-11-20-ficha-carrossel-design.md` para o comportamento da ficha).

## Global Constraints

- Arquivo único e offline; nenhuma dependência npm nova; nada baixado; sem rede.
- Português do Brasil. Termo em português + original em inglês + explicação curta (≤ 260 caracteres) + `pagina` só se conferida no livro.
- Texto parafraseado: nada copiado do manual; cada dica ≤ 200 caracteres, 2 a 3 por passo.
- Livro-fonte: `D:\Pichau\Downloads\Pdf's\Legend in the Mist TTRPG Core Rules.pdf`; extrair com `pdftotext -layout` para `D:\dev-tools\tmp\rules.txt` (nada grande no C:).
- Preferências em `localStorage` chave `lim-guia-v1`, sempre em `try/catch`; separadas da ficha (`lim-ficha-v1`).
- Acessível: região `complementary` com nome; interruptor com `aria-pressed`; glossário em `role="dialog"`, Esc fecha, foco volta; sem `aria-live` a cada troca de passo; `prefers-reduced-motion` respeitado; alvos ≥ 44 px.
- Nunca `innerHTML` com texto de dados: sempre nós de texto.
- Mobile (< 860 px): o mascote e o balão não cobrem o botão Próximo nem o rótulo do passo.
- Branch `feat/guia`; commits terminam com `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Os 92 testes existentes continuam passando.

## Review Focus

1. `localStorage` bloqueado: o guia funciona na sessão (ligado por padrão) e o interruptor liga/desliga sem lançar erro.
2. Guia desligado: mascote, balão, glossário e sublinhados somem de verdade; recarregar mantém desligado; foco não fica preso.
3. `linkTerms`: palavra dentro de outra ("Busca" em "Buscar"), maiúsculas/acentos, termo repetido (só a 1ª ocorrência), texto com `<`/`&` — tudo como texto, sem HTML.
4. Celular: balão e mascote não cobrem o Próximo; o glossário rola e fecha.
5. Teclado: Tab, Enter/Espaço no mascote e nos termos, Esc no glossário, foco devolvido, `aria-pressed` correto.

### Task 2: Funções puras do guia

**Files:** Create: `src/text.js`, `src/guide.js`, `test/guide.test.mjs`; Modify: `src/combo.js`, `src/carousel.js`, `test/carousel.test.mjs`.

**Interfaces:**
- Produces:
  ```
  // text.js
  export function norm(s: string): string            // NFD sem acentos, minúsculas, trim
  // carousel.js
  export function slideIdAt(i: number): string       // SLIDES[i].id ou 'revisao'
  // guide.js
  export type Term = { id: string, pt: string, en: string, curto: string, pagina?: number, apelidos?: string[] }
  export type Seg = { t: 'txt' | 'termo', v: string, id?: string }
  export const GUIDE_KEY = 'lim-guia-v1'
  export const defaultPrefs: () => { on: boolean, open: boolean }          // { on: true, open: true }
  export function loadPrefs(storage): { on: boolean, open: boolean }       // nunca lança; lixo/ausente -> padrão
  export function savePrefs(storage, prefs): boolean                       // nunca lança
  export function tipsFor(slideId: string): string[]                       // [] se desconhecido
  export function findTerm(id: string): Term | null
  export function searchTerms(query: string): Term[]                       // pt/en/curto, sem acento; vazio -> todos em ordem alfabética de pt
  export function linkTerms(text: string, terms?: Term[]): Seg[]           // só a 1ª ocorrência de cada termo; palavra inteira; juntar os `v` devolve `text`
  ```
  `guide.js` importa `GLOSSARY` e `TIPS` de `guide-data.js` (Task 3 os cria; nesta task use um `guide-data.js` mínimo com 3 termos e 1 passo, que a Task 3 substitui).
